AUC Calculation — Trapezoidal Methods

Area Under the plasma Concentration-time Curve (AUC) represents total drug exposure. Calculated from observed data using the trapezoidal rule — no compartmental model assumed.

Linear Trapezoidal Rule

AUC(t1→t2) = ½ × (C1 + C2) × (t2 - t1). Best used when concentration is rising (absorption phase). Overestimates AUC during steep decline.

Log-Linear Trapezoidal Rule

AUC(t1→t2) = (C1 - C2) / ln(C1/C2) × (t2 - t1). Best used when concentration is falling (post-Cmax). More accurate during monoexponential decline. Linear-log combination is the default in modern NCA software (WinNonlin, Phoenix).

AUC Extrapolation to Infinity

AUC(0→∞) = AUC(0→t_last) + C_last/λz. λz is the terminal elimination slope from semi-log regression of last 3 or more data points. The tail must represent ≤20% of total AUC for reliable extrapolation.

Clinical Use of AUC

Bioavailability: F = AUC(oral)/AUC(IV). Clearance: CL = Dose/AUC(IV). Bioequivalence: AUC ratio must be within 80–125%.
